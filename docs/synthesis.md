# Synthesis

## Overview

The SPI Master Controller was synthesized using **Xilinx Vivado** to verify that the RTL is fully synthesizable and to analyze the hardware resources and timing performance.

Synthesis converts the SystemVerilog RTL description into a gate-level hardware implementation targeting an FPGA device.

---

# Tool Information

| Item | Value |
|------|-------|
| Tool | Xilinx Vivado |
| Language | SystemVerilog |
| Design Type | RTL |
| Target FPGA | Artix-7 (xc7a35tcpg236-1) |

---

# Synthesis Flow

The following steps were performed in Vivado:

1. Create a new RTL project.
2. Add the SystemVerilog design source (`spi.sv`).
3. Set the top module.
4. Run RTL elaboration.
5. Verify the RTL schematic.
6. Run synthesis.
7. Analyze utilization reports.
8. Analyze timing reports.

The design synthesized successfully without errors.

---

# Timing Analysis

Static Timing Analysis (STA) verifies that the synthesized hardware can operate correctly at the desired clock frequency.

Vivado checks:

- Setup timing
- Hold timing
- Clock propagation
- Critical paths
